# 2026-09-17 — World Weather Info: Aurora Glass rewrite

## What was done

Full rewrite of the weather dashboard into an immersive glassmorphism design, plus
fixes for every reported bug.

### Fixed
- **Hourly forecast times** were indexed with the browser's clock
  (`new Date().getHours()`) against the API's city-local `hourly.time[]`. Now the
  current index is located by matching the API's own local ISO timestamps, and
  every label is parsed from those strings — all times are the city's local time.
- **Day/night icons** — WMO 0/1 always rendered a sun (and `Clear` a moon), with no
  `is_day` awareness in the hourly strip. Replaced the emoji map with a hand-built
  SVG icon set resolved from `(condition, isDay)`, using `is_day` from both
  `current` and `hourly`.
- **Temperature chart** — `<Line>` children inside `<AreaChart>` are silently
  dropped by Recharts. Switched to `ComposedChart`; added a 24 h / 7 day toggle.
- **AQI visuals** — rebuilt as a 270° gauge using `pathLength={100}`, value arc
  coloured by AQI band, marker dot instead of a needle (the needle cut through the
  number), and pollutant bars normalised against the worst pollutant with the
  WHO-guideline share annotated.
- **Global map** — replaced the hand-drawn blob with real Natural Earth outlines
  generated from TopoJSON (`src/data/worldMap.ts`), a live day/night terminator,
  pan/zoom, hover cards and click-to-select.
- **City search** — added a suggestion dropdown: instant bundled matches plus live
  Open-Meteo geocoding for any city worldwide, with keyboard nav; selecting loads
  that city's detail and scrolls to it.
- **Chart Y-axis labels** were clipped by `margin={{ left: -20 }}` ("100" → "00").
- **Theme preference was destroyed on every load** — hydration ran in an effect and
  React StrictMode's double-invoked effects re-read the value the other effect had
  just written. Moved to lazy `useState` initialisers plus a pre-paint inline script.
- **Dark theme rendered light text on a light background** — the ambient sky palette
  ignored the theme. `skyPalette()` now takes `theme` and branches on it first.
- **Fake data removed**: visibility was hardcoded to `10`, solar noon to
  `12:30 PM`, moon phase to "Waxing Crescent", and the city cards showed
  `rainProbability + 40` as an "AQI". All now come from the API or real computation.
- **50-city grid / map issued 100 HTTP requests** (one per city per endpoint). Now
  two batched requests with in-flight de-duplication and a 10-minute cache.
- **StrictMode/`w-full` Tailwind conflict** left the search input at full width.
- **`base: '/world-weather/'` in production** broke `vite preview`; now driven by
  the optional `VITE_BASE_PATH` env var, defaulting to `/`.

### Added
Live local clock, derived weather alerts, activity suitability scores, "best time
outdoors today", 48-hour hourly timeline with a temperature curve, 24 h/7 day trend
toggle, city sorting, favourites & recently-viewed bar, moon illumination, dew
point, cloud cover, MSL pressure, 5-layer parallax backdrop, pointer-tilt glass
cards, animated 3D globe, scroll progress bar.

### Repo hygiene
Added `.gitignore`; untracked `node_modules`, `dist` and `tsconfig.tsbuildinfo`
(`git rm --cached`, files left on disk).

## Verification

`npx tsc -b` clean, `npm run build` clean, and a 12-check browser suite passes
(hourly labels match the city clock, 6 chart surfaces with lines/bars/areas, 116
map land paths + 52 markers, AQI gauge, 50 city cards with real AQI, unit toggle
48°F → 9°C, theme persistence, zero runtime exceptions). No horizontal scroll at
1440 / 820 / 390 px.
